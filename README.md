# Имей Склад

Приложение для склада телефонов: сканер IMEI камерой, приход, продажи, рассрочки, аналитика, синхронизация между телефонами и компьютером. Работает на ПК, iPhone и Android, устанавливается как обычное приложение.

## Как запустить (один раз, ~15 минут)

Камера и установка работают только по защищённому адресу (https), поэтому папку нужно выложить в интернет. Это бесплатно.

### 1. Выложить папку на хостинг
Любой из вариантов:
- **Netlify Drop**: зайдите на app.netlify.com/drop и перетащите всю папку «Имей Склад». Получите адрес вида `https://что-то.netlify.app`.
- **Cloudflare Pages** или **GitHub Pages**: загрузите содержимое папки так же.

Откройте полученный адрес. Приложение уже работает на этом устройстве.

### 2. Включить синхронизацию (чтобы данные были на всех устройствах)
1. Создайте бесплатный проект на supabase.com.
2. Откройте **SQL Editor → New query**, вставьте содержимое файла `supabase-setup.sql`, нажмите **Run**.
3. В **Project Settings → API** скопируйте **Project URL** и ключ **anon public**.
4. В приложении: **Настройки → Синхронизация**, вставьте адрес и ключ, нажмите «Придумать код» и «Сохранить и подключить».
5. Нажмите «Скопировать ссылку» и откройте её на втором устройстве. Настройки подтянутся сами.

Важно: защита данных держится на длинном коде магазина и ключе. Не публикуйте ссылку-приглашение.

### 3. Установить
- **Компьютер (Chrome или Edge)**: значок установки в адресной строке или кнопка «Установить приложение» в Настройках.
- **iPhone**: откройте адрес в Safari → «Поделиться» → «На экран Домой».
- **Android (Chrome)**: меню → «Установить приложение».

### 4. Перенести старую таблицу
**Настройки → Данные → Импорт**: выберите CSV со столбцами Дата, Телефон, Цвет, IMEI, Поставщик, Цена. Пример: `sample-import.csv`. Из Google Таблиц: Файл → Скачать → CSV.

## Сканер
- Наведите камеру на штрихкод IMEI (на коробке или после набора `*#06#`). Принимаются только IMEI с верной контрольной суммой.
- При первом запуске на iPhone сканер скачивает библиотеку из интернета и дальше хранит её в кэше.
- Если штрихкод не читается: фонарик, «Загрузить фото», «Прочитать цифры» (распознавание текста, экспериментально) или ввод вручную. USB-сканер тоже работает: он вводит цифры в поле поиска.
- Короткий IMEI (последние 5 цифр) находится по концу номера. При скане полного IMEI можно дописать его в карточку.
